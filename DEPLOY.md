# Публикация на Cloudflare Workers

Cloudflare убрал Pages из интерфейса и перевёл всё на Workers — поэтому кнопки
«загрузить папку и всё заработает» больше нет. Сайт вместе с админкой ставится
из терминала несколькими командами. Ниже по шагам, без пропусков.

Всё бесплатно. Карта нужна только для необязательного пункта 6.

---

## 1. Node.js

Нужен один раз, чтобы работала команда установки.

Скачать LTS-версию: https://nodejs.org → большая кнопка (LTS) → установить,
везде «Далее». Перезагружать компьютер не нужно.

## 2. Распаковать архив

Распакуйте `anri-worker.zip` в удобное место, например на рабочий стол.
Внутри должны быть: файл `wrangler.json`, папки `public` и `src`.

## 3. Открыть терминал в этой папке

**Mac:** правой кнопкой по папке → «Новый терминал в папке».
Если такого пункта нет — откройте Терминал, наберите `cd ` (с пробелом),
перетащите папку в окно терминала и нажмите Enter.

**Windows:** откройте папку, кликните по адресной строке проводника,
наберите `cmd` и нажмите Enter.

## 4. Вход и первая публикация

Наберите по очереди, каждую строку с Enter:

```
npx wrangler login
```

Откроется браузер — разрешите доступ, вернитесь в терминал.

```
npx wrangler deploy
```

Первый раз спросит про установку — согласитесь (`y`). Через минуту терминал
покажет адрес вида `https://anri.anri-yusupov.workers.dev`. **Сайт уже живой.**

Админка — тот же адрес плюс `/admin`. Сохранять она пока не умеет, это пункт 5.

## 5. Хранилище правок и пароль

Создайте хранилище:

```
npx wrangler kv namespace create anri_data
```

Терминал напечатает строку с `id = "..."`. **Скопируйте этот id.**

Откройте `wrangler.json` в текстовом редакторе и добавьте блок `kv_namespaces`
(id подставьте свой):

```json
{
  "name": "anri",
  "main": "src/index.js",
  "compatibility_date": "2026-06-01",
  "assets": {
    "directory": "./public",
    "binding": "ASSETS"
  },
  "kv_namespaces": [
    { "binding": "SITE_KV", "id": "СЮДА_ВСТАВИТЬ_ID" }
  ],
  "observability": { "enabled": true }
}
```

Задайте пароль админки:

```
npx wrangler secret put ADMIN_PASSWORD
```

Терминал попросит ввести пароль — введите и нажмите Enter. Символы не
отображаются, это нормально.

Опубликуйте заново:

```
npx wrangler deploy
```

**Готово.** Заходите на `/admin`, вводите пароль — правки сохраняются и сразу
видны на сайте.

## 6. Загрузка файлов из админки (необязательно)

Нужно, только чтобы заливать новые видео и картинки прямо из админки.
Требует привязанной карты — в бесплатные 10 ГБ вы не выйдете.

```
npx wrangler r2 bucket create anri-media
```

Добавьте в `wrangler.json` рядом с `kv_namespaces`:

```json
  "r2_buckets": [
    { "binding": "MEDIA", "bucket_name": "anri-media" }
  ],
```

И снова `npx wrangler deploy`.

Без этого шага админка работает полностью — новые файлы просто выбираются
из тех, что уже лежат на сайте.

## 7. Домен, когда купите

В панели Cloudflare: **Compute → Workers & Pages → anri → Settings →
Domains & Routes** → **Add** → **Custom domain**. Сертификат выпускается сам.

---

## Как обновлять дальше

- **Тексты, проекты, кейсы, стол** — через админку, сохраняется мгновенно.
- **Код и новые эффекты** — заменить файлы в папке и снова `npx wrangler deploy`.

## Если что-то пошло не так

| Что видите | Что делать |
|---|---|
| `npx: command not found` | не установился Node.js — вернитесь к пункту 1 |
| «Пароль не настроен на сервере» | не сделан `wrangler secret put ADMIN_PASSWORD` |
| «Хранилище SITE_KV не подключено» | нет блока `kv_namespaces` в `wrangler.json` или забыли `deploy` после правки |
| «Загрузка файлов выключена» | не подключён R2 — нормально, если пропустили пункт 6 |
| Ошибка про `id` при deploy | в `wrangler.json` остался текст `СЮДА_ВСТАВИТЬ_ID` |

## Безопасность

Пароль хранится у Cloudflare как секрет, в файлах его нет. Вход держится 7 дней.
Сохранять правки может только вошедший; смотреть сайт — кто угодно.
