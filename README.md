# ANRI YUSUPOV — сайт-портфолио.

## Что где лежит

| Папка / файл | Что это |
|---|---|
| `public/index.html` | Страница: разметка, стили, загрузчик |
| `public/js/main.js` | Вся логика сайта |
| `public/js/three.min.js` | Библиотека для 3D-фона |
| `public/data/site.json` | **Контент**: проекты, тексты, контакты, слова на стене |
| `public/data/desk.json` | **Раскладка рабочего стола**: значки, папки, док |
| `public/media/` | Все картинки, видео, музыка, шрифты |
| `og.jpg`, `favicon.svg` | Превью ссылки и иконка вкладки |
| `_headers` | Правила кэширования (для Cloudflare Pages / Netlify) |
| `public/admin.html` | **Админка**: стол, кейсы, тексты |
| `src/index.js` | Серверная часть: вход, сохранение, загрузка файлов |
| `wrangler.json` | Настройки публикации |
| `DEPLOY.md` | Пошаговая публикация на Cloudflare Workers |

## Главное

Контент **отделён от кода**. Чтобы поменять текст, проект или значок на столе,
трогать код не нужно — правится только `data/*.json`. Именно на этом будет
работать админка: она пишет эти два файла, сайт читает их при каждом открытии.

## Локальный запуск

Открывать `index.html` двойным кликом **нельзя** — браузер запрещает читать
`data/*.json` с диска. Нужен сервер:

```bash
cd <папка сайта>
python3 -m http.server 8080
```

Дальше открыть http://localhost:8080

## Вес

Страница — 575 КБ, медиа — 14,5 МБ. Медиа грузятся по мере надобности,
первый экран открывается сразу.


## Админка

Открывается по адресу `/admin`, вход по паролю (задаётся на сервере).

- **Рабочий стол** — значки перетаскиваются мышью, папки наполняются файлами,
  док настраивается порядком и масштабом.
- **Кейсы** — карточка проекта и сборка страницы из блоков: заголовок, текст,
  цитата, картинка, две картинки, галерея, видео, ролик по ссылке.
- **Тексты** — имя, слова на типографической стене с розовыми подписями, «о себе», контакты.

Сохранение — кнопкой или `Ctrl/Cmd + S`. Правки видны на сайте сразу после перезагрузки страницы.
